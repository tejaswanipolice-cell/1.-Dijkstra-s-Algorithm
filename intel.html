🧠 Greedy Method

Dijkstra's algorithm finds the shortest path from one source vertex to all other vertices.

  1. Set the source distance to 0.
  2. Set all other distances to ∞.
  3. Select the unvisited vertex with minimum distance.
  4. Relax all its neighboring vertices.
  5. Mark the selected vertex as visited.
  6. Repeat until all vertices are visited.

Time Complexity: O(V²)
